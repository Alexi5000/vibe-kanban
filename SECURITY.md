# Security reporting

This policy covers the Alexi5000/vibe-kanban fork.

Use [GitHub private vulnerability reporting](https://github.com/Alexi5000/vibe-kanban/security/advisories/new)
to report a suspected vulnerability. Sign in to GitHub to submit a report.
Do not disclose exploit details, credentials, or private workspace data in a public issue.

Include the affected commit or version, operating system, relevant configuration,
reproduction steps, and expected security impact. Use sanitized examples and test
credentials; omit customer data and live secrets.

For ordinary bugs and feature requests, use the
[issue tracker](https://github.com/Alexi5000/vibe-kanban/issues).
This reporting policy does not establish a security audit, a supported-version
guarantee, or a response-time commitment.
